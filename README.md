(Sistema de Ordenação de Notas de Estudantes em C)

Objetivo
Desenvolver uma aplicação computacional na linguagem C para resolver uma situação do cotidiano acadêmico (organização de notas de estudantes), utilizando e comparando o desempenho dos algoritmos de ordenação Bubble Sort e Quick Sort.

Situação-Problema
Em uma instituição de ensino, os professores frequentemente precisam organizar as notas finais dos alunos em ordem crescente para identificar rapidamente o desempenho da turma, localizar notas mais baixas e mais altas, e facilitar a elaboração de relatórios pedagógicos e análises de rendimento escolar. Este sistema automatiza esse processo a partir de um conjunto de dados de estudantes.

Pré-requisitos e Instruções de Execução

Para compilar e executar o código localmente, siga os passos abaixo:

 Certifique-se de ter um compilador C instalado no seu sistema (como o GCC).
 Navegue até a pasta onde o código-fonte (c) está salvo utilizando o terminal do seu sistema operacional.
