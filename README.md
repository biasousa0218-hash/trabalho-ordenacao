Aplicação e Ordenarção de notas de estudantes 
Objetivo:
Desenvolver uma aplicação computacional na linguagem C para resolver uma situação do cotidiano ( organização de notas de estudantes) utilizando os algoritimos de ordernação Bubble sort e Quick Sort.

Situação problema 
Em uma instituição de ensino , os professores frequentimente presisam organizar as notas finais dis alunos em ordem crescente para identificar rapidamente o desempenho da turma, notas mais baixas e notas mais altas, facilitando a elaboração de relatórios pedagógicos.

Para compilar e execultar o codigo localmente:
Certifique-se de ter um compilador C intalado (como gcc).
